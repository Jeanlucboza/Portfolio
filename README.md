## 📖 Sobre o Projeto

Este portfólio foi desenvolvido para apresentar minha trajetória como Desenvolvedor Front-end, destacando os principais projetos que desenvolvi durante meus estudos. O design foi pensado para ser visualmente atraente, com animações suaves e totalmente responsivo para todos os dispositivos.

---

## 🚀 Funcionalidades

- ✅ Design moderno com gradiente e efeito glassmorphism

- ✅ Layout totalmente responsivo (mobile e desktop)

- ✅ Animações CSS suaves (fade-in, hover effects)

- ✅ Cards de projetos interativos com efeito de elevação

- ✅ Links diretos para projetos e redes sociais

- ✅ Efeito backdrop-filter nos botões de contato

---

## 🛠️ Tecnologias e Técnicas Utilizadas

| Tecnologia | Aplicação |
|------------|-----------|
| **HTML5** | Estrutura semântica com tags `header`, `section`, `footer` |
| **CSS3** | Estilização avançada |
| ↳ Grid Layout | Sistema de grid responsivo com `auto-fit` e `minmax()` |
| ↳ Flexbox | Alinhamento de elementos e tags |
| ↳ Gradientes | Background com `linear-gradient` |
| ↳ Animações | Keyframes personalizados (`fadeInDown`, `fadeInUp`, `fadeIn`) |
| ↳ Transições | Efeitos hover suaves com `transform` e `box-shadow` |
| ↳ Media Queries | Responsividade para telas até 768px |
| ↳ Backdrop Filter | Efeito blur nos botões de contato |
